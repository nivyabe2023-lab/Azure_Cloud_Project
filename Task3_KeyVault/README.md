#Task 3:Azure Key Vault
## objective 
Create Azure key Vault and Store a Sceret 
##Steps
1.create a Key Vault from Azure Portal.
2.Configure basic settings and access permissions.
3.Go to **Scerets-->Generate /Import **.
4.Add a secret with value 'ABCD@1234567'.
5.Save the secret successfully.

##Result
*Azure Key Vault Created
*Secret stored securely
